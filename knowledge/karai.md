# 카라이 라멘 / 매운 라멘 (辛いラーメン)

## 요약
하나의 정해진 스타일이라기보다 **고추의 매운맛이 중심인 라멘들의 묶음**이다. 이 프로젝트에서는 "국물이 붉거나 주황색인 매운 라멘"을 하나의 종류로 다룬다.

## 매운맛을 내는 재료
- 고춧가루·건고추, **라유(고추기름)**, 두반장, 가라미소(매운 된장).

## 대표적인 매운 라멘
- 탄탄멘(担々麺): 참깨와 라유가 들어간 매운 국물.
- 산라탕멘(酸辣湯麺): 시고 매운 국물.
- 마보멘(麻婆麺), 타이완 라멘, 가라미소 라멘 등.

## 사진으로 구분하는 법
- soup=yes, color=**red_orange**. 국물이 붉거나 주황색이다.
- 국물 위에 **고춧가루, 붉은 고추기름 층**이 보이는 경우가 많다.
- 미소 라멘과 구분: 미소는 황갈색. 붉은 기가 강하면 카라이 쪽.

## 프로젝트 관찰 (우리 사진 기준)
- karai_1: 주황색 탁한 국물 + 가는 직면 + 김 + 고춧가루 + 튀긴 양파.
- VLM이 색을 light_brown으로 잘못 봤다(정답 red_orange). 주황색과 연갈색의 경계를 헷갈린다.
